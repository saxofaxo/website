Gib das Admin-Passwort ein. Es wird nur für diese Sitzung gemerkt.

Ankündigung

Ein schmaler Hinweis-Balken oben auf der Website – z. B. für eine neue Single oder freie Termine. Schalter aus = kein Balken.

Neue Musik

Der Musik-Block auf „Über mich“. Leere Felder lassen den aktuellen Website-Stand unverändert. Neues Cover oder neue Hörprobe: kurz an die Agentur.

Ziel von Cover und Button („Auf allen Plattformen anhören“).

Referenzen

Eine Referenz pro Zeile. Sie erscheinen im Laufband der Startseite. Leer lassen = aktuelle Liste der Website behalten.

Änderungen sind nach dem Speichern sofort live (ggf. Seite neu laden). Fotos, Videos und Hörproben laufen weiterhin über die Agentur. Zur Website.
